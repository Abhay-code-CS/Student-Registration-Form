# Student Registration Form

A simple **Student Registration Form** created using pure HTML as a beginner web development project.

## Features

- Full name, email, and password fields
- Phone number and date of birth inputs
- Gender selection using radio buttons
- Multiple hobby selection using checkboxes
- Course and branch dropdown menus
- Address input using a textarea
- Register and Reset buttons
- Basic HTML form validation using the `required` attribute

## Technologies Used

- HTML5

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## Project Structure

```text
Student-Registration-Form/
├── index.html
└── README.md
```

## Note

This project is built using HTML only. It does not include CSS styling, JavaScript functionality, or backend/database integration. Form submissions are not stored.

## Learning Purpose

This project was created to practise HTML forms, input types, labels, radio buttons, checkboxes, dropdowns, and basic form validation.
